# 블로그 도우미

네이버 블로그 글쓰기를 돕는 갤럭시 탭용 앱. 채팅으로 사진과 줄거리를 주면(SP2) 어시스턴트가 계획을 제안하고 초안을 만들어 네이버 스마트에디터에 자동 입력하며, 발행은 사용자가 직접 한다.

## 채팅 사용법
1. 앱을 켜면 바로 채팅 화면이다. 왼쪽엔 대화 기록(세션 목록), 가운데 채팅, 오른쪽엔 초안이 들어갈 에디터 패널이 있다(좁은 화면에서는 대화 기록이 드로어로, 패널은 전체 화면 시트로 바뀐다). 아직 아무 말도 안 한 "새 글"은 가운데에 큰 제목("오늘은 어떤 이야기를 올릴까요?")과 큰 입력창만 보이고, 첫 메시지를 보내면 그때 대화가 만들어지면서 보통 채팅 모양이 된다.
2. 사진을 첨부하고("+" 버튼, 순서 변경·삭제 가능) 오늘 있었던 일을 한두 문장으로 적어 보낸다. 마이크로 음성 입력도 된다.
3. 어시스턴트가 글 계획(확정 제목·다른 제목 2개·글 구성·말투)을 **오른쪽 패널**에 정리해 준다. 마음에 안 드는 곳을 채팅으로 말하면("더 짧게", "사진 순서 바꿔 줘") 계획 전체를 다시 써서 패널을 갱신한다. 제목을 따로 고르는 단계는 없다.
4. 계획이 마음에 들면 입력창 위 "이대로 초안 써 줘" 버튼을 누른다 — 초안이 만들어지고, 오른쪽 패널이 계획에서 네이버 스마트에디터로 바뀌면서 초안이 채워진다.
5. 패널이 열린 채로 "문단 2를 더 짧게" 같은 수정을 요청하면 새 초안이 같은 에디터에 다시 채워진다(사진은 이미 올린 것을 재사용).
6. **앱은 초안을 에디터에 채워 넣는 것까지만 한다. 발행 버튼은 사용자가 패널 안 에디터에서 직접 눌러야 한다 — 앱이 자동으로 누르지 않는다.**
7. 어시스턴트가 필요하다고 판단하면(영업시간·주소·가격 등 사실 확인) 네이버 검색(안 되면 구글로 폴백)으로 자료를 찾아보고, 그 검색에서 나온 페이지만 열어 볼 수 있다. 검색 중에는 "네이버에서 '…' 정보를 찾고 있어요…" 같은 진행 상태가 말풍선 자리에 잠깐 보인다.
8. 발행이 끝나면 그 대화를 참고해 다음 글에 쓸 만한 취향·표현을 자동으로 기억해 두고 "이런 점을 기억해 둘게요: …" 메시지를 남긴다. 채팅 상단의 "기억한 것들"에서 언제든 읽고 고치거나 지울 수 있다.
9. 앱을 껐다 켜도 대화와 초안(발행 작업)은 그대로 남는다. 다시 켜면 패널은 닫힌 채로 열리므로, 상단의 "초안 열기"를 눌러 다시 펴면 이어서 쓸 수 있다.

## 관리자 설정
왼쪽 대화 기록 사이드바 맨 아래의 톱니 아이콘으로 들어간다(접힌 레일·세로 드로어에서도 같은 자리).
- **API 키**: 여러 줄로 키를 붙여넣으면 후보가 나오고, "등록"을 누르면 키마다 유효성을 검사해(`정상`/`한도 초과`/`무효`/`오류`) 유효한 키만 저장한다. 키는 서로 다른 프로젝트에서 발급해야 로테이션이 의미가 있다. 목록에서 키를 지울 수 있다.
- **모델과 글 길이**: 기본 모델·대체 모델 ID, 온도(0.0~2.0), 글 길이(최소/최대, 기본 1,200~1,800자 — 사용자 글 실측 중앙값 기준)를 직접 바꿀 수 있다.
- **프롬프트**: 시스템 프롬프트의 각 섹션(역할, 개인화 메모리, 글 구조 규칙 등)을 텍스트로 편집하고, 섹션별로 "기본값으로 되돌리기"가 가능하다. 저장하면 다음 대화부터 적용된다.
- **기억한 것들**: 자동으로 쌓인 메모리 항목을 문장으로 보고, 눌러서 수정·삭제하거나 켜고 끌 수 있다. 채팅 화면 상단에서도 같은 화면으로 갈 수 있다.
- **자료 검색 도구**: 켜고 끌 수 있는 토글. 끄면 어시스턴트가 검색·페이지 열기를 시도하지 않는다.
- **네이버 로그아웃**, **실패 로그**도 같은 설정 화면에 있다.

## 한도 안내
Gemini 무료 등급은 키(=프로젝트)마다 따로 적용된다. 2026-08-28 실측 기준:

| 모델 | RPM | TPM | RPD |
|---|---|---|---|
| `gemini-3.6-flash`(기본) | 5 | 250k | 20 |
| `gemini-3.7-flash` | 5 | 250k | 20 | (2026-08-29 현재 무료 등급에서 503 과부하가 계속돼 기본에서 제외)
| `gemini-3.5-flash-lite`(대체) | 15 | 250k | 500 |

429(한도 초과)를 만나면 키를 60초 쿨다운시키고 다음 키로 넘어간다. 한 모델에서 등록된 모든 키가 쿨다운이면 그 모델을 10분간 쉬고 대체 모델로 내려간다. 서버 과부하(503 등 5xx)는 키가 아니라 모델 문제이므로, 같은 키로 한 번만 더 시도한 뒤 바로 대체 모델로 내려간다. 503(과부하)은 재시도 없이 바로 대체 모델로 내려가고 그 모델을 5분간 건너뛴다(**503으로 거절된 요청도 RPD 에서 차감되는 것을 실측**했으므로 헛된 재시도를 막는다). 그 밖의 5xx 는 같은 키로 한 번만 더 시도한다. 모든 키·모델이 막히면 채팅에 "지금은 잠깐 쉬어야 해요. N분 뒤에 다시 시도할게요."가 뜨고, 재시도 칩이 나온다. 글 1편당 8~12회 호출을 가정하면, 서로 다른 프로젝트에서 발급한 키를 여러 개(예: 7개) 등록해 둔 경우 하루 1~2편은 한도에 여유 있게 들어간다. 생각 예산도 턴마다 다르게 준다 — 계획·피드백 턴은 thinking 을 낮게, 초안·수정 턴은 높게 요청한다(모델이 `thinkingConfig` 를 거절하면 그 필드만 빼고 한 번 더 보낸다).

## 개발
- Android Studio (AGP 9.3, JDK 17). `./gradlew :app:testDebugUnitTest :app:assembleDebug`
- 설계: `docs/superpowers/specs/`, 디자인: `docs/design-guide.md`, 에디터 규칙: `spike/findings.md`
- 에뮬레이터로 확인할 때는 API 35 이미지를 사용한다 (`minSdk`가 33이라 API 33/34/35 모두 실행 가능하지만 API 35로 검증했다).

## 릴리스
1. 최초 1회 서명 키 생성: `keytool -genkeypair -v -keystore release.jks -alias blogwriter -keyalg RSA -keysize 2048 -validity 10000`
2. GitHub Secrets 등록: `KEYSTORE_BASE64`(`base64 -w0 release.jks`), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
3. `git tag v0.3.0 && git push origin v0.3.0` → Releases 에 `blogwriter-v0.3.0.apk` 첨부
4. 태블릿에서 Release 페이지의 APK 를 내려받아 설치 (출처를 알 수 없는 앱 허용 필요)

로컬 서명 빌드: 루트에 `keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`) 를 두고 `./gradlew :app:assembleRelease`.

## 업데이트
앱이 시작할 때 새 버전을 확인하고, 새 버전이 있으면 채팅 화면 상단에 안내 배너를 보여 준다. 배너를 누르면 릴리스 페이지 맨 위 링크로 APK 를 내려받을 수 있다.

## 주의
- 개인용 도구입니다. 네이버·구글과 무관하며, 네이버 블로그 이용약관과 검색 서비스 정책을 지키는 책임은 사용하는 사람에게 있습니다. 발행 버튼은 앱이 누르지 않고 사용자가 스마트에디터에서 직접 누릅니다.
- 글은 LLM(Gemini)이 초안을 쓰고 사용자가 검토·수정합니다. 사실 확인은 사용자의 몫이며, 협찬·광고 표기는 앱이 다루지 않으므로 필요하면 직접 추가해야 합니다.
- 자료 검색은 앱 안의 숨은 WebView 로 검색 결과 페이지를 읽는 방식(턴당 최대 2회)입니다. 대량·자동 수집 용도로 쓰지 마세요.
- API 키는 기기 안에서만 암호화 저장되며 어디로도 전송되지 않습니다(Gemini 호출 헤더 제외).
